# Modern Robotics 学习项目

教材：*Modern Robotics: Mechanics, Planning, and Control*，Kevin M. Lynch 与 Frank C. Park，2017。

这是教材学习的记录包：以本地 PDF 为主要依据，保存当前进度、章节笔记、教师侧问答与教材图附件。项目层面的学习路线、优先级和章节取舍由项目中的「路线规划」对话维护，不写入本课程笔记。

## 目录说明

- `notes/chXX/`：每章一个文件夹，内含章节笔记 `chXX-<topic>.md` 与对应的教师侧 QA 记录 `chXX-<topic>-qa.md`；不记录学习者原始作答。
- `attachments/chXX/`：从教材截取、供同章笔记与 QA 直接嵌入的图。
- `sources.md`：教材版本、本地文件位置，以及笔记和图片的页码引用规范。
- `AGENTS.md`：供新 Codex agent 恢复课程的入口说明。
- `progress.md`：当前学习位置、已讲内容与下一步。
- `learning_protocol.md`：唯一的教学流程、笔记与状态规范。
